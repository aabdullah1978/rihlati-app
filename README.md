# رحلتي بعد التكميم — تطبيق أندرويد/آيفون (Capacitor)

هذا مشروع Capacitor جاهز يحوّل ملف `رحلتي-بعد-التكميم.html` إلى تطبيق حقيقي (APK لأندرويد)، مع الحفاظ على كل الوظائف والتصميم كما هو (نفس البيانات المحفوظة محليًا على الجهاز)، بالإضافة لأربع ميزات جديدة أضفتها فعليًا للتطبيق:

- **تصدير ومشاركة PDF عبر واتساب:** زر "تصدير ومشاركة تقرير PDF" يجهّز تقرير اليوم (الوجبات، المياه، البروتين، الوزن) كملف PDF ويفتح شاشة المشاركة القياسية لأندرويد (تقدري تختاري واتساب أو أي تطبيق ثاني منها مباشرة).
- **نسخ احتياطي واستعادة:** زر "تصدير نسخة احتياطية" يصدّر كل بيانات التطبيق كملف JSON واحد (تقدري تحفظيه أو ترسليه لنفسك)، وزر "استعادة من نسخة احتياطية" يرجّع البيانات من نفس الملف على أي جهاز.
- **سجل التغييرات (Audit Log):** بطاقة جديدة بتعرض آخر 50 حدث بالتطبيق (وجبة اتسجلت، كوب مية، وزن اتحفظ، إلخ) مع التاريخ والوقت بالضبط.
- **إشعارات تذكير:** بطاقة "التذكيرات" فيها 3 مفاتيح تشغيل/إيقاف لتذكير شرب الماء (كل ساعتين)، تذكير الفيتامين (9 صباحا)، وتذكير مواعيد الوجبات — تشتغل حتى لو التطبيق مقفول.

فيه طريقتان لبناء ملف APK:

---

## الطريقة 1 (الأسهل): بناء أونلاين مجاني عبر GitHub Actions — بدون تثبيت أي برنامج

هذا المشروع فيه ملف جاهز (`.github/workflows/build-apk.yml`) يخلي GitHub نفسه يبني لك ملف APK مجانًا على سيرفراته، وترجعي تنزّليه جاهز. الخطوات:

1. اعملي حساب مجاني على [github.com](https://github.com) (لو ما عندك حساب).
2. اضغطي "New repository" وسمّيه مثلاً `rihlati-app` (خليه Public أسهل، أو Private إذا حبيتِ).
3. من صفحة الريبو الفاضية، اختاري رابط "uploading an existing file"، وبعدين اسحبي *كل الملفات والمجلدات* اللي جوا الزip بعد فك ضغطه (`android`, `www`, `.github`, `package.json`, إلخ) وارفعيها، ثم اضغطي "Commit changes".
4. روحي لتبويب **Actions** أعلى صفحة الريبو — هيبدأ بناء تلقائي اسمه "Build Android APK" (ياخد حوالي 3-6 دقائق).
5. لما ينتهي (علامة ✓ خضراء)، افتحي الـ workflow run، وتحت "Artifacts" هتلاقي ملف `rihlati-app-debug-apk` — نزّليه، وجواه ملف الـ APK.
6. انقلي ملف الـ APK لموبايل الأندرويد (عبر واتساب لنفسك مثلاً)، وثبّتيه (لازم تسمحي بـ"تثبيت من مصادر غير معروفة" أول مرة).

هذا مجاني 100% (GitHub بيدي دقائق تشغيل مجانية كل شهر، تكفي بمرات كتير)، وما بيحتاج تثبيت Android Studio ولا أي شيء على جهازك.

> ملاحظة: إذا حبيتِ تشغّلي البناء يدويًا بعد أول مرة (بدون رفع تعديل جديد)، افتحي تبويب Actions → اختاري "Build Android APK" من القائمة اليسار → زر "Run workflow".

---

## الطريقة 2: بناء محلي عبر Android Studio (لو حابة تجربي التطبيق مباشرة على جهاز موصول أو تعدّلي الأيقونة بسهولة)

1. فكّي ضغط الملف في أي مجلد على جهازك.
2. افتحي Terminal داخل المجلد وشغّلي:
   ```
   npm install
   npx cap sync android
   ```
3. افتحي مجلد `android` من داخل [Android Studio](https://developer.android.com/studio) (مجاني).
4. انتظري "Gradle Sync" (أول مرة تاخد بضع دقائق لتنزيل الأدوات).
5. Run ▶ لتجربته على موبايل/محاكي، أو Build → Build APK(s) لإنشاء الملف مباشرة.

---

## بناء تطبيق آيفون (لاحقًا، يحتاج جهاز Mac)
```
npx cap add ios
npx cap sync ios
npx cap open ios
```
البناء والتشغيل من Xcode. يحتاج حساب Apple Developer (مجاني للتجربة، 99$/سنة للنشر على App Store). للأسف ما فيه بديل مجاني أونلاين لهذا الجزء — شرط من Apple نفسها إن أي بناء لآيفون يحتاج جهاز Mac.

## ملاحظة حول الإشعارات والصلاحيات
أول مرة تفعّلي أي تذكير، التطبيق هيطلب إذن الإشعارات من أندرويد (شاشة تظهر مرة واحدة). لازم توافقي عليها حتى تشتغل التذكيرات. الصلاحيات المطلوبة (إشعارات، وصول لملفات التطبيق الداخلية لتصدير PDF/JSON) تتضاف تلقائيًا لملف الأندرويد عند البناء، مافيه أي إعداد يدوي مطلوب.

## معلومات المشروع
- **اسم التطبيق:** رحلتي بعد التكميم
- **معرّف الحزمة (Package ID):** com.driyadeid.rihlati
- **الملف الأساسي:** `www/index.html` (نفس محتوى ووظائف الملف اللي رفعتيه، مع إضافة الميزات الأربع الجديدة فقط)
- **أيقونة التطبيق:** حاليًا أيقونة Capacitor الافتراضية — تقدري تغيّريها من Android Studio عبر New → Image Asset، أو أرسلي لي شعار وأحدّثه بنفسي.
- البيانات (الوجبات، الوزن، المياه، سجل التغييرات...) بتتخزن محليًا على جهاز المستخدمة فقط، بدون أي خادم خارجي. ملفات الـ PDF والنسخ الاحتياطي بتتصدّر مباشرة من الجهاز عبر شاشة المشاركة القياسية، بدون رفعها لأي سيرفر.
